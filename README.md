# Sales & Customer Analysis Dashboard

## Project Overview

This project presents an interactive Sales and Customer Analysis Dashboard created using Microsoft Power BI.

The dashboard provides a clear overview of sales performance and customer-related insights using interactive visualizations and filters.

## Tools Used

- Microsoft Power BI
- Excel / CSV
- Data Cleaning
- Data Analysis
- Data Visualization

## Dashboard Features

- Total Sales KPI
- Total Customers KPI
- Total Orders KPI
- Sales by Product Category
- Sales by State
- Sales by Marital Status
- Gender Analysis
- Interactive State Filter
- Interactive Gender Filter
- Interactive Marital Status Filter

## Key Insights

The dashboard helps analyze:

- Overall sales performance
- Sales distribution across product categories
- Sales performance across different states
- Customer distribution by gender and marital status
- Top-performing areas based on sales

## Interactivity

Users can interact with the dashboard using slicers for:

- State
- Gender
- Marital Status

The charts and summary cards update dynamically based on the selected filters.
